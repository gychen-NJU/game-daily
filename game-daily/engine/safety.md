# 安全红线

这些规则优先级高于"把流程跑完"。任何一条被触发，都要停下来报告。

## 1. 权限与 UAC

- 需要提权时，**一次只弹一个** UAC，并且弹之前先说清三件事：为什么要提权、点了之后能做什么、不做会怎样。
- 用户拒绝过一次 → **不要再弹**；改为输出「手动步骤清单」让用户自己在游戏里点。
- 不允许用"绕过 UAC / 关掉 UAC / 改注册表"等办法。
- `Start-Process -Verb RunAs` 会阻塞调用线程并切到安全桌面；**全屏游戏运行时不要临时弹 UAC**（会把游戏挤掉），要么提前起好助手，要么等游戏退出。

## 2. 前台与输入

- 只对**目标游戏窗口**发输入；执行前校验前台窗口标题，不是游戏就报错。
- 不抢用户正在操作的窗口；一次任务结束后把前台交还给用户原来的窗口。
- 全屏游戏 + 焦点锁定：除点击/按键本身外，不做无关的键盘输入。

## 3. 绝不点击的东西

- **付费按钮**：`解锁无名客的勋礼`、任何"购买""充值""礼包"确认。
- **破坏性按钮**：删除存档、重置账号、退出登录、分解/销毁物品（除非流程明确写了且用户在同一次对话里确认）。
- **不确定的按钮**：图上看不清、文案看不懂、位置和 `expect` 描述不符 → 停手问。

## 4. 资源花费

- 花体力/开拓力/抽卡券之前，确认这是流程里写明的步骤（例如"累计消耗 120 点开拓力"），并记录花费。
- 流程没写"要花多少"时，**按流程给的次数上限**执行，不多花。
- 出现"资源不足"提示 → 停手报告，不自动补（不自动买石头/不自动用道具补充）。

## 5. 隐私与交付物

- 截图落盘/交付前脱敏：**账号 UID、昵称、邮箱、订单号**遮掉；**非目标应用与聊天/会话内容**整块遮掉（例：从启动器截图里裁掉背景的 DSH 界面）。
- 标注图必须从**已脱敏的原图**重新生成，否则会把旧内容带回来。
- 运行日志与截图只写本地模块 `state/`，不随技能分发、不主动外发。

## 6. 反作弊与账号安全

- 只用"读屏 + 点击/按键"这种与真人操作等价的输入；不注入游戏进程、不改内存、不替换 DLL、不模拟封包。
- 星铁/原神/绝区零等有反作弊；自动化频率要像人（步骤之间留 300–1500ms，不用连点器狂点）。
- 出现"环境异常/检测到第三方软件" → 立即停止，报告用户。

## 7. 用户接管

- 用户说"我来/停/先别动" → 立刻停，交还控制权，回到只读状态。
- 用户手动操作过后，界面状态可能与流程假设不一致：重跑前先 `shot` 认屏。
