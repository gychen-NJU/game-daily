# 星铁跑法（模块内专用）

> 家族通用跑法在 `../../engine/runbook.md`；这里只写星铁独有、踩过坑的部分。

## 1. 启动链（不在游戏里时）

1. `launcher.exe`（`E:\miHoYo Launcher\`，进程 HYP）——已开就激活，没开就 `Start-Process`（它会静默自提权，不弹 UAC）。
2. 启动器**默认停在崩坏3页**（`config.ini [hyp] primary_game=bh3_cn`）→ 点左侧**星铁图标**切到星铁页。
   - ⚠️ **不要按"第几个图标"找**：它排在第几位取决于本机装了几个米哈游游戏（有人是第 2 个，也会是第 1/3/4 个）。
   - **按图标认**：粉发角色 wink 笑、异色瞳、圆角方形、底部 muHoYo 字样（对照 `references/screens/launcher-sr-icon.png`）。
   - 确认方式：悬停出 tooltip「崩坏：星穹铁道」；或点下去后标题变「月升之前，与兽共舞」。
   - 找不到就**截图问用户**，不要挨个图标乱点（点错会切到别的游戏页，甚至触发更新）。
   - 判据：标题变「月升之前，与兽共舞」；悬停图标会出现 tooltip「崩坏：星穹铁道」。
3. 点右下「开始游戏」→ 大约 10 秒后游戏窗口出现（`UnityWndClass`，全屏 2560×1600）。
4. 等黑屏 → 星穹列车加载 → 标题界面（底部「点击进入」）。
5. 点「点击进入」：
   - 成功 → 出现「欢迎进入游戏」toast → 进世界
   - 弹「登录异常…1001_1」→ 点「确认」→ **再点一次「点击进入」**（本机无代理也会偶发）
6. 进世界后若弹「列车补给 / 点击领取今日补给」→ 这是步骤 1。

> 启动链是**前置动作**，不属于 14 步日常。日常从"已经在游戏世界里"开始。

## 2. 键位与面板

| 键 | VK | 作用 | 注意 |
|---|---|---|---|
| `F4` | 115 | 打开星际和平指南（每日实训） | **只在世界界面生效**；其它面板开着时按了没反应 → 先 `ESC` |
| `F2` | 113 | 打开无名勋礼 | 同上，需先关面板 |
| `ESC` | 27 | 关面板 / 返回 | 弹窗（获得物品）用点空白更稳 |

## 3. 界面与坐标的易错点

1. **指南任务卡横向滚动**：`领取` / `前往` 按钮的 x 会随卡片位置漂移。默认坐标是"第一张卡"的位置；如果目标卡在别的列，用 `guide.task_claim_c2`（第 2 列）或 `_c3`（第 3 列），**不要盲点左右**。
2. **`一键领取` 的 y 比看起来高**：无名勋礼任务页按钮实际在 y≈1300（相对 0.8125），按视觉中心 0.86 会点空。
3. **`获得物品` 弹窗**会挡住后续点击，先 `popup.close_blank`（点 1280,1400 空白）。
4. **委托**：领取奖励后通常自动续派（4/4、0/30 小时），**没有**「一键派遣」按钮，别硬找。
5. **体力/次数**：副本每次 40 开拓力（隧洞）/10（花萼）；`sr-daily.json` 里写的"加到最大"由当时的开拓力决定，执行前用截图确认上限，不要按上次的数字连点。
6. **付费陷阱**：奖励页「解锁无名客的勋礼」是付费项（¥680），`honor.onekey_reward` 与它挨得很近，**点之前确认落点是左侧的「一键领取」**。

## 4. 一步的正确姿势（以步骤 8 为例）

```
截图 → 认屏：看到「侵蚀隧洞 / 挑战次数 / 挑战」？
  否 → 停（可能还在生存索引，或版本改了界面）
  是 → 读当前次数与上限 → 点「+」(calyx.plus) 到上限 → 截图确认数字变了
       → 点「挑战」(calyx.challenge) → 截图确认进入队伍页
```

每一步都按这个套路：**先确认在哪，再动手，再确认结果变了**。不要连着一串点击不看屏幕。

## 5. 日常结束状态

- 指南活跃度 500/500，五个礼盒能领的都领了
- 无名勋礼「任务」与「奖励」两个 tab 的「一键领取」都点过
- 副本已退出（回到副本选择页或世界）
- 可选：回到世界界面，把控制权交还用户
