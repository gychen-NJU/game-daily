# 崩坏3 跑法细节（runbook-hi）

`references/hi-daily.json` 是机器可读版；这里写「人/agent 看屏幕时要拿捏的分寸」。

## 前置：从启动器到进入世界

| 阶段 | 判据 | 动作 | 等多久 |
|---|---|---|---|
| 启动器（别的游戏页） | 页面标题不是「时序照新」 | 点左侧「崩坏3」图标（白/银角色 + 10 周年角标） | 1–3 s |
| 启动器（崩坏3 页） | 标题「时序照新 V9.1」，右下黄按钮 | 点「开始游戏」 | — |
| LOADING | 顶部 LOADING + 「检查资源更新…」 | 什么都不点 | 20–40 s |
| 标题界面 | 顶部橙色 IDENTIFYING + 底部「点击任意处进入游戏」 | 屏幕任意处点一下 | 10–20 s |
| 进世界 | 弹出「每日签到」28 天面板 | 点底部「领取」→「确定」 | — |

## 主界面长什么样

左侧竖排：任务 / 活动 / 福利 / 邮件 / 公告 / 商城；底部：舰团 / 家园；
右侧六边形：装备 / 出击 / 协同者 / 女武神 / 补给。顶部：等级、历练值、体力、金币、水晶。

## 顺序与衔接（最容易犯的错）

1. **金币采集不是家园那个管**：金币采集通常由「作战任务 → 一键领取」完成（1/1）。
   家园里「金币标志对应的管」点下去弹的是「**体力补充 / 取出体力 ×144**」。
2. **打工要「先领奖、再派工」**：右下「领取奖励」亮着就先点它，再点「一键打工」。
3. **打工地图没有「主菜单」**：必须点两次左上「返回」才能回到有底部导航的页面。
4. **远征**先随手「完成远征」一条拿奖励，再「一键远征」→「远征派遣」。
5. **委托 8 次**：第 1 次要先「申请新委托 → 一键申请」，之后每次循环
   申请新委托 → 一键申请 → 提交 → 提交委托 → 放入舰团奖励池。
6. **每日历练值 600** 在进度条**最右端**，不是左边那几个 100/200/300/450。

## 停手清单（任一命中即停）

- `expect` 文案对不上（版本更新改了 UI）
- 同一坐标连点两次画面无变化
- 出现付费 / 删除 / 重置按钮（例如「解锁无名客的勋礼」这类礼包）
- 体力/饭团不够、要不要继续花 → 交给人
- 用户说停
