# game-daily-hi · 崩坏3 每日日常

`game-daily` 家族的崩坏3 模块。**14 步全部在本机实跑过**（2026-10-23），含打工子步 5.5。

## 覆盖什么

| # | 步骤 | 关键动作 |
| --- | --- | --- |
| 1 | 主界面 → 任务 | 左上「任务」 |
| 2 | 作战任务 · 一键领取 | 领登录 + 体力奖励 |
| 3 | 金币采集（可选） | 「前往」；通常已被步骤 2 完成 |
| 4 | 家园 → 远征 | 底部「远征」 |
| 5 | 完成一条远征 → 一键远征 | 完成远征 → 确定 → 一键远征 → 远征派遣 |
| **5.5** | **打工** | **先「领取奖励」（亮着才点）→ 一键打工 → 确认 → 返回 ×2** |
| 6 | 主菜单 → 任务 → 舰团委托前往 | — |
| 7 | 申请新委托 → 一键申请 | 1/10 → 10/10 |
| 8 | 提交 → 提交委托 → 放入舰团奖励池 ×8 | 剩余次数打到 0/8 |
| 9 | 舰团奖池领取 | 右侧第二个页签 |
| 10 | 主菜单 → 任务 → 材料活动前往 | — |
| 11 | 一键减负 → 减负 → 确定 | 吃 67 体力 |
| 12 | 主菜单 → 任务 → 一键领取 | 历练值 250 → 800 |
| 13 | 每日历练值 600 | 进度条**最右端**图标 |

跑完约 **10–12 分钟**。

## 用法

```powershell
cd "$HOME\.agents\skills\game-daily"

node scripts/probe.mjs --game hi --pretty        # 自检
node scripts/coords.mjs check --game hi          # missing=0
node scripts/run-step.mjs --game hi --all        # 打印 14 步计划
```

在 agent 里说「**帮我清崩三日常**」「崩坏3 每日」即可路由到本模块。

## 崩坏3 特有的坑（都实跑踩过）

1. **金币采集不是家园那个管**：金币采集由「作战任务 1/1 → 一键领取」完成；
   家园里「金币标志对应的管」点下去弹的是「体力补充 / 取出体力 ×144」。
2. **打工顺序**：先「领取奖励」（灰着 = 还没到 14 小时，跳过）→ 再「一键打工」。
3. **打工地图没有「主菜单」**：必须连点两次左上「返回」回到有底部导航的页面。
4. **「金币采集 · 前往」可能进「回收委托」**：按钮文案与实际跳转不一致，按页面标题确认。
5. **弹窗两种高度**：`dialog.ok`(1280,1165) 与 `popup.ok2`(1280,1142) 别混用。
6. **奖励页的「解锁…礼包」绝不点**（付费）。
7. **键盘注入未验证**：本模块全程只用鼠标。
